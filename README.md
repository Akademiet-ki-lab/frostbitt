# FROSTBITT ❄️🎣

Et norsk isfiskespill laget med HTML5 Canvas, vanlig CSS og JavaScript – ingen byggesteg eller eksterne filer.

**Spill her:** https://akademiet-ki-lab.github.io/frostbitt/

## Slik spiller du
- Gå med piltastene (eller A/D), hold SPACE for å bore et hull, og slipp ned snøret med ↓.
- Pilk i rytme med SPACE for å lokke fisken, og sveiv inn fangsten når det napper.
- Hold deg varm med kaffe (K) og jag bort reven (F) – hunden hjelper deg.
- Runden varer i 5 minutter. Poengene dine spares i en lommebok du kan bruke i butikken.

## Filer
- `index.html` – siden
- `style.css` – utseendet
- `script.js` – spillet (lyd lages med Web Audio API)
